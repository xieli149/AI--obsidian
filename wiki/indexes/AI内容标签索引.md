# AI 内容知识图谱入口

当前知识图谱采用三层结构：**文章过程文件 → 文章项目索引 → 核心概念**。

- 标签只负责区分创作阶段和少量主题，避免图谱出现无意义的大节点。
- “所属项目”链接把访谈、大纲、初稿、定稿和发布记录收拢到同一个文章项目。
- “相关概念”链接把不同文章项目和素材连接成跨文章的知识网络。

## 创作阶段

#内容阶段/选题 → #内容阶段/访谈 → #内容阶段/大纲 → #内容阶段/初稿 → #内容阶段/改稿 → #内容阶段/定稿 → #内容阶段/发布稿

辅助节点：#内容阶段/配图素材、#内容阶段/核验、#内容阶段/发布记录、#内容阶段/历史文章、#内容阶段/外部素材

## 文章项目

```dataview
TABLE WITHOUT ID file.link AS "文章项目", 内容类型 AS "类型", 目标受众 AS "受众", 相关概念 AS "核心概念"
FROM #索引/文章项目
SORT file.name ASC
```

## 使用图谱

1. 打开 Obsidian 左侧的“关系图谱”。
2. 标签节点已经开启，无关模板和原始输出已过滤。
3. 点击某个核心概念查看跨文章关联；点击文章项目查看完整创作链路。
