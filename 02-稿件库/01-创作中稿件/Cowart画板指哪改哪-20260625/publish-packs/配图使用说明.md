# 配图使用说明

本次使用 `lizi-illustrations` 重新生成了 4 张正文配图，均为 16:9 横版。旧版小黑配图保留在 `images-final/` 中作为历史版本，正文已全部切换到下面的 Lizi 新图。

## 已生成配图

1. `images-final/01-lizi-point-where-to-edit.png`
   - 放在开头“以前靠文字描述，现在可以画板圈注”段落后。
   - 作用：一眼解释 Cowart 最大价值，指哪里改哪里。

2. `images-final/02-lizi-cowart-codex-workflow.png`
   - 放在“Cowart 的大致流程”段落后。
   - 作用：解释打开画板、放原图、圈一下、生成新图、对照看。

3. `images-final/03-lizi-no-ps-workbench.png`
   - 放在“运营/内容人适用场景”段落前。
   - 作用：把公众号封面、正文配图、海报这些真实场景串起来。

4. `images-final/04-lizi-windows-safety-boundary.png`
   - 放在 Windows 安全提醒段落后。
   - 作用：解释“不是不能用，是要把本地服务和权限边界画清楚”。

## 建议补充的真实截图

文章里已经预留两个截图位：

1. Cowart 画板里，原图 + 红圈标注 + 箭头。
2. 原图和生成后的新图放在一起对比。

这两张最好用你的真实操作截图，不需要精修，保留一点真实使用痕迹更可信。

截图放入 `images-final/` 后，建议命名：

- `05-real-annotation.png`
- `06-real-before-after.png`

然后把正文里的截图位替换成：

```markdown
![我的 Cowart 标注截图](images-final/05-real-annotation.png)

![原图和新图对比](images-final/06-real-before-after.png)
```
