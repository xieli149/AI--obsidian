# 发布说明

## 文件

- `公众号精排版正文-含图片-预览用.md`：Obsidian 预览用，图片使用 `file://`。
- `公众号精排版正文-含图片-同步用.md`：Wechatsync 同步用，图片使用相对路径。
- `images-final/`：同步到公众号草稿箱使用的最终图片。

## 同步命令

```bash
WECHATSYNC_TOKEN="$WECHATSYNC_TOKEN" wechatsync sync "公众号精排版正文-含图片-同步用.md" -p weixin
```

## 检查项

- 同步用正文第一行是正式标题。
- 同步用正文不含 frontmatter。
- 同步用正文不含发布说明。
- 同步用正文不含 `file://`。
- 同步用正文不含 `/Users/` 绝对路径。
- 同步用正文没有独立水平分割线。
- 图片文件都在 `images-final/` 中。
