# 运营必备AI工具推荐11：hatch-pet，给 Codex 换一只自己的电子宠物｜文章大纲

## 核心角度

这篇文章不再从技术结构切入，而是先回答读者最关心的三个问题：Codex 宠物是什么、长什么样、到底是好玩还是真有用。读者建立兴趣后，再进入“自己怎么做”，最后补充九行动画、宠物包、图集尺寸等底层知识，达到拓宽视野的效果。

## 读者

- 已经在用 Codex，但还不知道自定义宠物是什么的人
- 看到宠物功能后觉得有趣，但不知道它有没有实际用途的人
- 想给 Codex 做个人形象、品牌感小助手或工作台氛围的人
- 能接受复制提示词，但不想手工拼图的小白用户

## 新结构

1. 开头先解释：宠物不是游戏宠物，而是 Codex 工作台里的小状态牌。
2. 用“待机、等待、执行、审阅、失败”说明它长什么样、怎么动、有什么用。
3. 回答“只是好玩吗”：好玩是入口，实际用途是状态可视化、降低工具冰冷感、形成个人/品牌工作台识别。
4. 补充 Codex 自带宠物：Settings → Appearance → Pets 可以选择内置宠物、刷新自定义宠物，也可以用 `/pet` 或命令菜单控制浮动宠物。
5. 进入自定义制作：安装 `hatch-pet`，遇到下载失败可让 Codex 改用 git 方式。
6. 给可复制提示词：名字、风格、形象、动作要求、注意事项。
7. 补充风格选择：像素、毛绒、黏土、贴纸、3D 玩具、品牌灵感等。
8. 后半段讲底层：skill 和宠物包不是一回事，最终读取的是 `pet.json` 和 `spritesheet.webp`。
9. 解释九行动画和图集尺寸，帮助读者理解为什么不能简单换一张图。
10. 结尾把视野拉高：这不是随便生图，而是“生成内容 + 规则整理 + 自动校验 + 应用资产”的小型生产线。
